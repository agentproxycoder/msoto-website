# msoto.org — Maryland Society of Otolaryngologists

Static website (plain HTML/CSS/JS). Hosted on Render as a static site; `msoto.org` points here.

- Pages: `index.html`, `about.html`, `membership.html`, `events.html`, `advocacy.html`, `sponsors.html`, `contact.html`
- Assets: `assets/` (logo, skull texture, sponsor logos, `site.js`)
- No build step. Render publish directory: `.`
